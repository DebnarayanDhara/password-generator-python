# Advanced Password Generator in Python

An advanced command-line Password Generator built using Python. It can generate strong random passwords with custom length, multiple password generation, clipboard support, entropy estimation, pronounceable passwords, and file management features.

---

## Features

-  Custom Password Length (1–10)
-  Generate Multiple Passwords (1–15)
-  Character Type Selection
-  Strong Random Password Generation
-  Exclude Similar Characters (`0`, `O`, `1`, `l`, `I`)
-  Pronounceable Password Mode
-  Copy Password to Clipboard
-  Password Entropy Estimate
-  Password Strength Checker
-  Custom File Name
-  Clear Existing File
-  Save Passwords to File
-  Play Again Option
-  Input Validation
-  Avoid Duplicate Passwords
